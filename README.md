# The SMART Modern Public School, Qamber — sample website

Static HTML/CSS/vanilla JS. No build step: open `index.html` or host the folder on any static host (GitHub Pages, Netlify, etc.).

- English / اردو toggle (RTL, remembered in localStorage)
- Pages: Home, About, Admissions, Fees & Timings, Gallery, Contact
- Gold **Placeholder** badges mark details still to be confirmed by the school (principal, fees, timings, board, session dates, documents, counts, founding year)
- The inquiry form is a demo: no data is sent
- "Chat with us" is a placeholder for a future AI admissions assistant

Sample website designed by Ecom Agent Lab. Photos are from the school's public Facebook page.
